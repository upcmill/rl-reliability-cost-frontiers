# Public Deposition README

This archive contains the formal v3 reinforcement-learning evaluation study
and its later, explicitly scoped extensions through the V7 new-seed validation.
It includes current English and Chinese manuscripts, supplementary materials,
source code, raw metrics, deterministic analyses, and reproduction records.

## Scope

The primary claim is conditional: under the preregistered task family,
training budget, evaluation protocol, and confidence procedure, the study
characterizes reliability--cost behavior. The archive does not support a new
RL algorithm claim, universal seed savings, universal compute efficiency, or
an algorithm ranking beyond the stated task family and budget.

## Archive contents

- v3 preregistration, raw seed-level metrics, summaries, and audit reports;
- v4--v6 scope and resolution-cost extensions, kept separate from the v3
  primary estimand;
- V7 frozen plan, lock, 15,000-row raw dataset, analysis outputs, and audit;
- current Chinese and English Word manuscripts, supplementary information,
  third-round audit, and key-literature full-text comparison;
- source code, environment locks, reproduction manifests, and SHA-256 hashes;
- same-workspace recomputation and different-machine rerun artifacts;
- literature search records and the current evidence-boundary documents.

## Reproduction limits

The included Windows rerun supports different-machine reproducibility of the
frozen protocol. It does not establish independent-team scientific
replication because the external operator identity and relationship to the
authors remain `[待补充]`. Earlier pilot, v1, and v2 outputs are archival and
are not pooled with the v3 primary estimand.

## Evidence limits and metadata

The Zenodo concept DOI supplied for this project is
`10.5281/zenodo.23949004`. The original v3.0.1 record has been superseded by
the updated V7-era archive under the same concept DOI. A concept DOI identifies
the version family and resolves to its latest published version, while each
release also has a version-specific DOI.

The public creator metadata currently contains only the repository account
`upcmill`. The following author-confirmed details remain incomplete and must
not be guessed:

- author names, affiliations, correspondence, and ORCID;
- author contributions, funding, competing interests, and license;
- external rerun operator identity, if stronger independence wording is used.

These fields are tracked in `SUBMISSION_METADATA_TEMPLATE.md` and
`CITATION_CFF_TEMPLATE.yml`. Bracketed values are placeholders and are not
claims.

The current package describes V7 as a post-hoc prospective new-seed validation,
not as confirmation of the original preregistration, unknown-distribution
coverage evidence, task-population inference, compute savings, or independent
team replication. The external Windows rerun remains distinct from an
independent-team scientific replication.

The record metadata, author list, and license must be checked against the
authors' instructions when creating a new Zenodo version. See
`PUBLIC_ARCHIVE_VERIFICATION.md` for the prior-version comparison and the
remaining metadata checks.
