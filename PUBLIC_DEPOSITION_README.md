# Public Deposition README

This archive contains the source files, preregistration records, raw metrics,
derived analyses, manuscript files, and reproduction materials for the v3
reinforcement-learning evaluation study.

## Scope

The primary claim is conditional: under the preregistered task family,
training budget, evaluation protocol, and confidence procedure, the study
characterizes reliability--cost behavior. The archive does not support a new
RL algorithm claim, universal seed savings, universal compute efficiency, or
an algorithm ranking beyond the stated task family and budget.

## Archive contents

- v3 preregistration, raw seed-level metrics, summaries, and audit reports;
- English and Chinese manuscript files and supplementary information;
- source code, environment locks, reproduction manifests, and SHA-256 hashes;
- same-workspace recomputation and different-machine rerun artifacts;
- literature search records and the current evidence-boundary documents.

## Reproduction limits

The included Windows rerun supports different-machine reproducibility of the
frozen protocol. It does not establish independent-team scientific
replication because the external operator identity and relationship to the
authors remain `[待补充]`. Earlier pilot, v1, and v2 outputs are archival and
are not pooled with the v3 primary estimand.

## Required metadata before publication

The following values must be completed by the authors or repository owner:

- author names, affiliations, correspondence, and ORCID;
- author contributions, funding, competing interests, and license;
- public repository URL or DOI and release/tag;
- data/code availability statement;
- external rerun operator identity, if stronger independence wording is used.

These fields are tracked in `SUBMISSION_METADATA_TEMPLATE.md` and
`CITATION_CFF_TEMPLATE.yml`. Bracketed values are placeholders and are not
claims.

## Suggested deposition workflow

1. Publish the code and archive contents in a public GitHub repository or
   institutional repository.
2. Create an immutable release/tag, then archive that release with Zenodo,
   OSF, Figshare, or an institutional repository.
3. Record the DOI, URL, version, license, release date, and downloaded archive
   SHA-256 in `SUBMISSION_METADATA_TEMPLATE.md`.
4. Re-run the public-archive safety audit and the submission readiness audit
   after replacing placeholders.

No public DOI or URL is asserted by this local archive.
