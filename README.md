# RL Reliability--Cost Frontiers: v3 Submission Archive

This repository is a public-deposition staging area for the v3 reinforcement-learning evaluation study.

The archive contains the manuscript source, supplementary information, preregistration records, raw seed-level metrics, analysis scripts, audit reports, and reproduction materials. The primary claim is conditional on the disclosed task family, budget, validation/test split, and finite-look interval procedure. It does not claim a new RL algorithm, universal seed requirements, universal compute savings, or guaranteed publication.

## Files

- `submission_bundle_v3.tar.gz`: source and artifact archive.
- `submission_bundle_v3.tar.gz.sha256`: SHA-256 checksum for the archive.
- `PUBLIC_DEPOSITION_README.md`: scope, evidence boundary, and deposition instructions.
- `CITATION_CFF_TEMPLATE.yml`: citation metadata template awaiting author and DOI confirmation.

## Verification

The local archive passed the public-archive sanitization audit. The latest local SHA-256 is recorded in the sidecar file. After uploading, download the GitHub release asset and recompute the checksum before citing this repository in a manuscript.

## Publication metadata

Author names, affiliations, license, DOI, and contact information remain placeholders until confirmed by the authors. This staging repository is not a substitute for a Zenodo or other immutable DOI record.
